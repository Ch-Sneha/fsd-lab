# Synchronous File Operations

## Deployment Link
https://synchronous-file-operations.onrender.com

## Operations Used
- `writeFileSync()` – Creates and writes data into a file.
- `readFileSync()` – Reads data from a file.
- `appendFileSync()` – Appends data to a file.
- `unlinkSync()` – Deletes a file (commented in the code).
