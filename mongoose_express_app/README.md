# Mongoose Express App

A REST API built using **Node.js, Express.js, and MongoDB with Mongoose**.

## Live Deployment

https://mongoose-express-app-bmm8.onrender.com

## Technologies Used
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- dotenv

## API Endpoints

Base URL: `https://mongoose-express-app-bmm8.onrender.com`


 GET - `/api/v1/movies` - Get all movies 
 POST - `/api/v1/movies`  Add a new movie GET  `/api/v1/movies/:id`  Get a movie by ID 
PUT  `/api/v1/movies/:id`  Update a movie 
 DELETE  `/api/v1/movies/:id`  Delete a movie
