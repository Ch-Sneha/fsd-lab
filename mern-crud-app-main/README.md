# MERN CRUD App

A full-stack CRUD application built using the MERN stack to manage blog posts with Create, Read, Update, and Delete operations.

## Live Demo

Frontend: https://merncrudfrontend-o3x19aer8-sneha-projects7.vercel.app

Backend API:https://mern-crud-backend-ro8m.onrender.com

## Features
- Create new posts
- View all posts
- View individual posts
- Update existing posts
- Delete posts
- MongoDB database integration

## Technologies
- MongoDB
- Express.js
- React.js
- Node.js
- Mongoose
