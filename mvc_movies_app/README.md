# MVC Movies App

Movie Management API built using Node.js, Express.js, MongoDB and Mongoose.

Live URL: https://mvc-movies-app-0ubn.onrender.com

## API Endpoints

GET: Get All Movies https://mvc-movies-app-0ubn.onrender.com/api/v1/movies

POST: `/api/v1/movies` – Add a movie

GET: `/api/v1/movies/:id` – Get movie by ID

PUT: `/api/v1/movies/:id` – Update a movie

DELETE: `/api/v1/movies/:id` – Delete a movie
