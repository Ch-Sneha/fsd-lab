# MVC Auth App

Authentication and Todo REST API built using Node.js, Express.js, MongoDB and JWT.

Live URL: https://mvc-auth-app-a896.onrender.com

## API Endpoints

Test API: [Open API](https://mvc-auth-app-a896.onrender.com/)

Todos: `/api/v1/todos`

Users:`/api/v1/users`

## Features
- User Authentication
- JWT Authorization
- Todo CRUD Operations
- MongoDB Integration
