# Template Engine EJS App

A CRUD-based Product Management application built using Node.js, Express.js, MongoDB, Mongoose, and EJS.

Live Demo: https://template-engine-jl2m.onrender.com

## Features
- Add new products
- View all products
- View product details
- Update product information
- Delete products
- EJS template rendering
- MongoDB database integration

## Technologies
Node.js, Express.js, MongoDB, Mongoose, EJS
